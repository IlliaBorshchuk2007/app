# Розклад уроків

Статичний сайт (HTML + JS) + Supabase. Без збірки: Vercel роздає файли як є.

1. Виконайте `supabase.sql` у Supabase SQL Editor.
2. Впишіть URL і ключ у `config.js`.
3. Залийте на GitHub і підключіть репозиторій до Vercel (Framework: Other).

Відкрийте сайт — створиться новий розклад, а адреса стане `?s=<id>`. Це посилання і є «доступ для всіх».
